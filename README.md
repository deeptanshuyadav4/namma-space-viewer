# Namma Space web viewer

Compiled build of the Namma Space web viewer (Techfest 2026-27, IIT Bombay):
walk through a 3D Gaussian-splat reconstruction of a real indoor space in the browser.

Live: https://deeptanshuyadav4.github.io/namma-space-viewer/

Desktop: click, then mouse to look, WASD to walk, Shift faster, F fly mode, M map.
Phone: left thumb joystick to walk, right thumb drag to look.
